📊 Project Overview

This project analyzes Uber ride booking data to understand business performance and customer behavior.

🛠 Tools Used

Microsoft Excel (Data Cleaning)

Tableau Desktop (Dashboard Creation)

🎯 Objectives

Analyze trip trends and revenue

Identify peak booking hours

Study cancellation behavior

Evaluate customer satisfaction

📈 Key Insights

Peak hours show higher cancellation rates

Certain vehicle types drive higher revenue

Ratings impact trip completion

Fare distribution varies across vehicle types
