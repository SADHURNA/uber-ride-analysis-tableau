🚗 Uber Ride Analysis – Tableau Dashboard
📊 Project Overview

This project analyzes Uber ride booking data to evaluate business performance, operational efficiency, and customer behavior.

The dataset was cleaned and prepared using Microsoft Excel and visualized through interactive dashboards in Tableau Desktop.

The objective is to uncover demand patterns, revenue trends, cancellation behavior, and service quality insights to support data-driven business decisions.

🎯 Problem Statement

Ride-hailing platforms generate large volumes of transactional data.
However, without structured analysis, it becomes difficult to:

Identify peak demand hours

Analyze cancellation trends

Monitor revenue performance

Understand customer satisfaction patterns

This project aims to transform raw ride-level data into actionable business insights using Tableau dashboards.

🛠 Tools & Technologies Used

Microsoft Excel (Data Cleaning & Feature Engineering)

Tableau Desktop (Dashboard Development & Visualization)

📂 Dataset Information

The dataset contains ride-level booking details including:

Booking ID

Trip Date

Pickup & Drop City

Vehicle Type

Booking Status

Fare Amount

Payment Method

Customer Rating

CTAT / VTAT metrics

🧹 Data Preparation Process

Loaded raw dataset into Excel

Removed duplicate and irrelevant fields

Handled missing values

Standardized data types

Created calculated features:

Hour of booking

Completion Rate

Cancellation Rate

Estimated Distance

Imported cleaned dataset into Tableau

📈 Dashboards Created
📌 Dashboard 1 – Business Performance Overview

Key KPIs:

Total Trips

Total Revenue

Average Fare

Insights:

Certain vehicle types contribute higher revenue

Revenue trends vary across cities

Peak hours significantly impact trip volume

📌 Dashboard 2 – Ride & Customer Analysis

Key KPIs:

Average Customer Rating

Average CTAT

Insights:

Higher booking volume during peak hours leads to increased cancellations

Customer ratings influence trip completion rates

Fare distribution differs across vehicle categories

Demand patterns vary by vehicle type and time

Advanced Visualizations Used:

Heatmaps

100% Stacked Bar Charts

Dual-Axis Trend Charts

Box Plots

Bubble Charts

🔎 Key Business Insights

Peak booking hours show higher cancellation rates

High-demand vehicle types drive revenue growth

Service quality directly affects customer ratings

Pricing variation exists across vehicle categories

💡 Recommendations

Improve driver availability during peak hours

Reduce cancellation through better ETA communication

Optimize pricing strategies for high-demand segments

Focus on service quality to increase customer satisfaction
